# Portfólio de Rodrigo Marques

Portfólio pessoal em HTML, CSS e JavaScript, publicado pelo GitHub Pages a partir da raiz da branch `main`.

## Estrutura

```text
index.html
assets/
├── css/style.css
├── js/main.js
└── img/
    ├── prumo.svg
    ├── rodrigo.svg
    └── rodrigo-profile.webp
```

Abra `index.html` no navegador para visualizar localmente ou execute `python3 -m http.server 8000` nesta pasta. Para publicar atualizações, envie `index.html`, `README.md` e a pasta `assets/` para a raiz do repositório e faça commit na branch `main`.

Na seção de projetos próprios, Prumo e RDG Motoboy têm links HTTPS separados para demonstração e código-fonte. A foto de Rodrigo foi incluída no cabeçalho do perfil; CSS, JavaScript e imagens continuam organizados em `assets/`.
