# Portfólio — Rodrigo Marques

Site estático em HTML, CSS e JavaScript, organizado em pastas para facilitar a edição. O projeto Prumo foi incluído na seção **Projeto próprio**, com links para a demonstração publicada e o repositório no GitHub.

## Estrutura

```text
index.html
assets/
├── css/style.css
├── js/main.js
└── img/
    ├── prumo.svg
    └── rodrigo.svg
```

## Abrir localmente

Abra `index.html` no navegador ou rode `python3 -m http.server 8000` nesta pasta e acesse `http://localhost:8000`.

## Atualizar o GitHub Pages

Envie `index.html`, `README.md` e a pasta `assets/` para a raiz do repositório do portfólio, preservando a estrutura. Os caminhos são relativos, então o site também funciona publicado em um subdiretório.
